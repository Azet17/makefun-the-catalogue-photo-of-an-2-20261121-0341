Entry for **"The Catalogue Photo of an Impossible Gadget"** — a studio catalogue
photograph of the **Ice-Kettle 3000**: a polished chrome electric kettle that,
instead of boiling water, pours ice cubes out of its spout into a ceramic mug.
The absurd job reads at a glance: a kettle producing ice.

The image is drawn procedurally with Pillow — chrome gradient body, curved
spout, brushed-metal handle, tumbling translucent ice cubes, faint cold
vapour, and a soft studio shadow on a warm-grey backdrop.

## Run

```sh
python3 draw.py        # renders entry.png (1024x1024)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # copies entry.png to out/
```
